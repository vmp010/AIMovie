# Northline Air —《它說可以》拍攝網站

依 `AIMovie_Realism_Improvement_Spec.md` 與《它說可以》的大綱與腳本調整現有原生 HTML、CSS、JavaScript 網站，保留七場順敘與場次網址。

**純拍攝道具，無真實訂位、付款、上傳、寄信或申訴送件。** Northline Air、Alex Chen、航班號、訂位代碼、郵件與內部工單為虛構；主要日期與金額參考公開裁決，不能一概視為虛構資料。未使用後端、AI API、CDN 或外部字型。

## 本機開啟

在本資料夾的 PowerShell 執行：

```powershell
python -m http.server 5500 --bind 127.0.0.1
```

- 拍攝首頁：<http://127.0.0.1:5500/index.html?film=1>
- 劇組首頁：<http://127.0.0.1:5500/index.html?crew=1>
- 亦可使用 VS Code Live Server，並換成實際啟動的埠號。
- 建議桌機 1920×1080、縮放 100%。手機版亦可使用。

## 操作模式

`film=1` 隱藏劇組說明、Reset、設定齒輪、場次入口與跨系統捷徑。航空公司旅客頁保留訂票、政策、申請與登機證服務；個人信箱、內部工單、裁決文件使用各自版面。劇中裁決仍保留「戲劇化重製／非正式法律文件」標示。

無參數或 `crew=1` 是劇組模式；兩個參數同時存在時，以 `crew=1` 優先。模式由網址決定，不使用黏住的工作階段設定；站內連結與搜尋跳轉會保留模式。拍攝中要回劇組，將 `film=1` 改為 `crew=1` 即可。

劇組左下角提供：

- **場次入口**：開啟各場固定畫面。
- **重播場次**：重新載入目前場次。
- **Reset Demo**：清除本站 `northline_demo_v1` 固定訂單、申請狀態與已讀紀錄，再重播目前場次。
- **進入拍攝**：以目前頁面和場次切到 `film=1`。

航空公司頁面聊天齒輪另提供「重新開始對話」與正常／結尾模式切換。重新開始對話會取消等待中的回覆。第一至六場不帶結尾免責聲明；第七場才顯示。重新開啟第二場會自動回正常模式。

## 互動範圍

- 公開頁首將「喪親優惠」與「票價差額申請」收進預設關閉的「旅客服務」選單。首頁不再放大型喪親優惠橫幅，只在一般服務卡片保留入口；第一場可先展開旅客服務看到優惠名稱，再開啟 AI 詢問，無須先進入政策全文。
- 僅支援 **11/12 YVR → YYZ、11/18 YYZ → YVR** 的來回行程，11/11 一次購票，含稅總價 **C$1,630.36**。其他航線或去回程日期顯示無航班。
- 預設付款方式是虛構 Visa `•••• 1103`；沒有卡號輸入欄位或付款服務。
- 完成付款後，`bookings.roundtrip` 保存一筆訂單、兩段航班與一筆總額，取代舊版單程紀錄；成功頁提供去程與回程登機證。3-2 是可直接預載的拍攝場次，即使未先購票也可展示，不會寫入新訂單。
- 申請表預填虛構資料，允許排演時修改。姓名、訂位碼、理由與航段會反映在確認和成功畫面，輸入文字只留在當頁記憶體，重新整理即復原。只保存固定申請日期與道具案件編號。
- 附件按鈕只選取 `supporting-document.pdf` 的預設標籤，沒有讀取、上傳或產生真正證明文件。
- Maple Mail 收件匣 2 封、已寄出 1 封，數量由資料計算。4-3 自動開啟已寄出的證據信。劇組模式可預覽草稿，沒有真實寄送。
- 聊天使用固定規則與台詞。手動輸入「請問喪親優惠如何申請？」、快捷問題與 1-6 都包含非真人客服營業時間、中性介紹及政策連結。2-2 固定重建 1-6 問答後接續九十天回答；其他手動對話不跨頁保存。非航空公司頁面不掛航空客服聊天元件。
- 後台登出僅切換展示畫面，沒有真正身份驗證；不可用於商用或真實個資系統。

## 真實案例與戲劇改編

案例為 **Moffatt v. Air Canada, 2024 BCCRT 149**。

- [CanLII 裁決入口](https://www.canlii.org/en/bc/bccrt/doc/2024/2024bccrt149/2024bccrt149.html)
- [本次核對使用的裁決 PDF 副本（The Sedona Conference）](https://www.thesedonaconference.org/sites/default/files/meeting_paper/Moffet%20v%20AirCanada.pdf)

先前核對時，CanLII 與審裁處直接連結未能由查閱工具載入，改讀上列裁決 PDF：第 18 段記載兩次單程購票日期／價格；第 20～22 段記載 11/17 申請、2/5 證據信與 2/8 回覆；第 44 段列出 C$650.88 損害賠償、C$36.14 判決前利息與 C$125 程序費，合計 C$812.02。

**2026/11/16 依最新拍攝需求，網站改為 11/11 一次購買來回票，總價 C$1,630.36，3-2 改成查看已訂回程。** 這是劇情操作的簡化，取代原腳本分次購票流程。總額不再拆成原有 C$794.98／C$845.38，也沒有新增折扣或以票價差額推算裁決賠償。

公開政策「完成旅行後不得追溯」保留案件核心意思。**購票時申請、一般票價購票後不得調整**是 Northline Air 的簡化劇情規則，非真實政策逐字引述，也不是對原案件的完整法律分析。它用來說明 11/17 回程尚未搭乘時，劇中公司為何仍拒絕申請。

客服／主管的內部備註、非真人客服營業時間、拒絕信的具體時刻，以及敗訴後只增加免責聲明的結尾，均屬戲劇化創作。原裁決未確認使用 ChatGPT、GPT-4 或任何特定大型語言模型。第六場以書面文件呈現，未製作真實法庭印章或機關徽章。

資料來源畫面與片尾應保留：**「改編自真實事件，部分情節為戲劇創作」**及中文在地化改編說明。原始 DOCX 與改善規格未修改。

## 離線與資料限制

所有頁面資源均在本機；斷開外網但保留 localhost 伺服器仍可拍攝。只有使用者主動按資料來源中的外部連結才需網路。拍攝模式的隱藏是視覺呈現，並不是權限隔離。
